# Отчёт по заданию A1: Ansible Vault

## 1. Что такое Ansible Vault и какой алгоритм шифрования он использует?
Ansible Vault — встроенный механизм шифрования файлов в Ansible. Использует алгоритм AES-256 (Advanced Encryption Standard с 256-битным ключом). При шифровании добавляет заголовок $ANSIBLE_VAULT;1.1;AES256.

## 2. Почему важно использовать no_log: true?
Параметр no_log: true предотвращает вывод секретов в логи Ansible. Без него пароли и ключи будут видны в выводе ansible-playbook и логах CI/CD систем.

## 3. Что произойдёт, если забыть vault-пароль?
Файл будет невозможно расшифровать. Ansible Vault не имеет механизма восстановления пароля. Потребуется создать новый vault-файл с новыми секретами.

## 4. Почему файл config.ini имеет права 0600?
Права 0600 означают: владелец может читать и писать, группа и остальные — нет доступа. Это предотвращает чтение паролей другими пользователями системы.

## 5. Как передать vault-пароль в CI/CD?
Использовать переменные окружения в GitLab CI:
- echo "$VAULT_PASSWORD" > .vault_pass
- ansible-playbook deploy.yml --vault-password-file .vault_pass
Где $VAULT_PASSWORD — защищённая переменная в настройках проекта.
