# Отчёт по заданию A3: encrypt_string

## 1. Разница между encrypt (файл) и encrypt_string (строка)
encrypt шифрует весь файл целиком, результат — зашифрованный файл.
encrypt_string шифрует отдельную строку, результат — YAML-тег !vault | с зашифрованным значением.

## 2. Когда шифровать файл, а когда строку?
Файл: когда много секретов (10+), централизованное управление, разные команды работают с разными файлами.
Строка: когда 1-2 секрета внутри роли, быстрое шифрование без создания отдельного файла.

## 3. Что означает !vault | в YAML?
!vault — YAML-тег, который говорит Ansible расшифровать значение. | — индикатор literal block scalar (сохранить переносы строк).

## 4. Как расшифровать строку вручную?
Никак без Ansible и правильного пароля. Для просмотра использовать: ansible-vault view secrets.yml --vault-password-file .vault_pass
