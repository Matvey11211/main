## Тема: Развёртывание веб-сервера с Ansible

## Цель
Автоматизировать развёртывание Nginx на целевых узлах с использованием Ansible.

## Выполненные задачи
1. Настроен файл инвентаризации (`inventory/hosts.ini`) с группами хостов.
2. Создана Ansible-роль `nginx` для структурирования задач (tasks), переменных (defaults) и шаблонов (templates).
3. Написан основной плейбук `deploy-nginx.yml` для применения роли к целевым узлам.
4. Выполнена проверка идемпотентности: повторный запуск плейбука не приводит к изменениям в системе.
